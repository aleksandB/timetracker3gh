## Подробности реализации

### 1. Иерархическая структура типов
```typescript
export interface Type {
  id: number;
  name: string;
  parentId: number | null; // null for top-level types (1-100), non-null for subtypes
}
```
- ID 1-100: доступны для назначения проектам с parent_id=null
- Остальные ID: для подпроектов с parent_id!=null

### 2. Древовидная структура проектов
```typescript
export interface Project {
  id: string;
  parentId: string | null; // Для иерархической структуры
  name: string;
  typeId: number; // Ссылка на Type.id
  shortName?: string;
}
```
