## 🔴 Критические проблемы (требуют немедленного исправления)

### Проблема 1: timeEntrySlice не разделяет записи по пользователям

**Текущая ситуация:**
```typescript
// ❌ useTimeTrackingData.ts - берет ВСЕ записи
const entries = useSelector((state: RootState) => state.timeEntries);

// ❌ TimeTracker получает все entries без фильтрации
<CalendarGrid entries={entries} ... />
```

**Решение:**
1. Добавить фильтрацию по `currentUser.id` в `useTimeTrackingData`
2. Создать селектор для получения entries текущего пользователя
3. Убедиться что `userId` всегда устанавливается при создании entry

**Файлы для изменения:**
- `src/lib/hooks/useTimeTrackingData.ts`
- `src/store/selectors/timeEntrySelectors.ts` (создать)
- `src/components/features/TimeTracker/index.tsx`

## 🔄 НОВАЯ АРХИТЕКТУРА: Иерархические проекты и типы

### Изменение структуры проектов и направлений

**Проблема:**
- Текущая структура: направления привязаны к проектам (один проект - несколько направлений)
- Ограничение: одно и то же направление не может быть добавлено к разным проектам
- Необходимость: поддержка древовидной структуры проектов

**Решение:**
1. Создать иерархическую систему типов (Type) с поддержкой родительских элементов
2. Перевести проекты на древовидную структуру с parentId
3. Разорвать жесткую связь проектов и направлений - направления теперь привязаны к проектам в записях времени
4. Добавить поддержку древовидного выбора проектов в UI

**Новая структура:**
- Type: {id, name, parentId} - иерархическая система типов (ID 1-100 доступны для проектов с parent_id=null, остальные для подпроектов)
- Project: {id, parentId, name, typeId, shortName} - древовидная структура проектов
- TimeEntry: {id, userId, directionId, projectId, date, regular, overtime, description} - теперь содержит projectId
- User: {id, name, role, position, projectIds} - теперь содержит список проектов

**Файлы для изменения:**
- `src/entities/project/types.ts` - добавить Type и обновить Project
- `src/store/slices/projectSlice.ts` - добавить поддержку Types
- `src/components/shared/AddProjectDialog.tsx` - обновить для древовидного выбора
- `src/components/features/DirectoryManagement/ProjectManagementUI.tsx` - обновить для новой структуры
- `src/components/features/DirectoryManagement/hooks/useProjectManagement.ts` - обновить для новой структуры
- `src/store/slices/initSlice.ts` - обновить для загрузки Types
- `public/initial-data.json` - обновить структуру данных
